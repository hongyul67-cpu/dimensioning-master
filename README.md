# 📏 치수기입 마스터 — 치수를 어디에, 어떻게 적는가

**기초제도 Ⅱ. 제도의 규격과 통칙 — 치수 기입**(제도 허브 분류 `기초제도 Ⅱ-4`) 단원용 학습·수업 보조 도구입니다.
설치 없이 브라우저에서 바로 실행되며, HTML 파일 하나로 오프라인·휴대폰에서도 작동합니다.

🔗 **바로가기:** https://hongyul67-cpu.github.io/dimensioning-master/

## 왜 만들었나

치수 기입은 규칙이 잘게 쪼개져 있어(단위·화살표 비율·보조선 여유·기호 12종·중복 금지)
설명을 들을 때는 알겠는데 막상 도면을 그리면 틀립니다.
그래서 **규칙을 외우게 하지 않고, 틀린 도면을 보여 주고 무엇이 틀렸는지 짚게** 만들었습니다.
Ⅳ영역이 통째로 「자주 하는 실수」인 것은 그 때문입니다.

## 구성

| 모드 | 내용 |
|------|------|
| 📖 **배우기** | 영역 3개 · 카드 10장. 그림(SVG)과 함께 규칙을 하나씩 |
| 📐 **치수 기입의 요소** | 치수선·치수 보조선·화살표·치수 숫자, 긋는 규칙과 숫자 방향 (문항 9) |
| 🔤 **치수 보조기호** | φ R □ t C SR Sφ ⌒ ( ) 밑줄 — 기호가 뜻하는 것 (문항 10) |
| ✅ **기입 원칙과 실수** | 집중·중복 금지 원칙, 자주 하는 실수 바로잡기 (문항 9) |
| 🎯 **종합시험** | 세 영역에서 7 + 7 + 6 = **20문항**을 섞어 출제하고 **결과 제출** |
| 📽️ **수업 슬라이드** | 교실 앞 화면용 **19장** (Ⅰ 5 · Ⅱ 6 · Ⅲ 3 · Ⅳ 5) |

> 배우기를 먼저, 테스트를 뒤에 둡니다. 학생이 규칙을 보기 전에 문제부터 만나지 않도록 한 배치입니다.

## 다루는 규칙 (교과서 표현 그대로)

| 갈래 | 핵심 |
|------|------|
| 단위 | 길이는 **mm**, 단위 기호는 **붙이지 않는다.** 각도는 도(°)·분(′)·초(″) |
| 화살표 | 길이 : 너비 = **3 : 1**, 길이 **2.5~3mm**. 한 도면에서 모양·크기를 같게 |
| 지시선 | 가는 실선, 수평선에 대해 **60°**. 도형 안에서 끌어낼 때는 화살표 대신 **흑점** |
| 치수 보조선 | 외형선에서 끌어내며 **치수선을 2~3mm 넘겨** 그린다 |
| 치수선 | 작은 치수는 안쪽, 큰 치수는 바깥쪽. 간격 **10mm** 정도로 나란히 |
| 치수 숫자 | 치수선 **중앙 위쪽**에. 수평은 위쪽, 수직은 왼쪽에서 읽도록 |
| 보조기호 | φ 지름 · R 반지름 · □ 정사각형 변 · t 두께 · C 45° 모따기 · Sφ 구 지름 · SR 구 반지름 · ⌒ 원호 |
| 괄호·밑줄 | ( ) 참고 치수 · <u>밑줄</u> 척도대로가 아닌 치수(NS) |
| 원칙 | **주 투상도에 모아서** · **완성된 뒤의 치수**를 · **중복 없이** · 도형 **바깥쪽**에 |

> **φ 와 R 을 가르는 기준** — **완전한 원**이면 **φ**(치수선이 원을 가로지른다),
> **원호**이면 **R**(중심에서 호까지 긋는다). 둥근 모서리(필렛)는 원이 아니라 호라서 **R** 입니다.
> R 을 지름으로 잘못 읽으면 크기가 **절반**이 됩니다. 이 한 가지가 가장 자주 틀립니다.

## 자료의 출처

- **기초제도**(씨마스 · 2015 개정) Ⅱ단원 「제도의 규격과 통칙」 중 **치수 기입**
  (단원 위치는 `drawing-master-hub` 의 분류 `기초제도 Ⅱ-4` 를 따랐습니다)
- 용어와 수치(3:1 · 2.5~3mm · 60° · 2~3mm · 10mm)는 교과서 표현을 그대로 씁니다. 바꾸지 않았습니다.
- 문항 28개는 위 규칙 범위 안에서 **자작**했습니다. 시험 원안을 옮긴 것이 아닙니다.

## 수업에서 쓰는 법

- **수업 자료**: `📽️ 수업 슬라이드 열기` → 요점 → 발문 → 퀴즈 → 정답이 클릭 한 번씩 열립니다.
  요점 속 **파란 빈칸**은 눌러야 답이 보이므로, 학생에게 먼저 물어보고 여세요. 화면 어디든 바로 판서됩니다.
- **형성평가(제출)**: 주소 뒤에 `?rc=<Apps Script URL>` 을 붙여 배포하면, 종합시험 종료 시
  학생이 **반·번호**를 넣어 제출하고 결과가 구글 시트에 모입니다.
  ```
  .../dimensioning-master/?rc=https://script.google.com/macros/s/.../exec
  ```
- **모두 같은 문제로**: 주소 뒤에 `?fix=1` 을 붙이면 문제·보기 순서가 고정됩니다(`fixorder.js`).
- **평가 루브릭**: `rubric.json` 에 성취기준·관찰 포인트가 수준별로 들어 있습니다.

## 저장소 안의 파일

| 파일 | 무엇 |
|------|------|
| `index.html` | 도구 본체 — 배우기(`LEARN`) · 문항은행(`BANK`) · 그림 함수(`figElements` 등) |
| `lesson.js` | 수업 슬라이드 **원고만**. 그림은 `index.html` 의 SVG 함수를 그대로 부른다 |
| `rubric.json` | 평가 루브릭 |

> **화면(뷰어)은 이 저장소에 없습니다.** `links/board-pro.js` 공용 하나를 불러 씁니다.
> 뷰어를 고칠 일이 생기면 여기가 아니라 `links` 를 고칩니다.
>
> `SYMBOLS` 는 `window.SYMBOLS` 로 내보내 슬라이드가 같은 데이터를 씁니다 — **한쪽만 고치면 어긋납니다.**
